THE NATHAN DRAKE COLLECTION

Bring your own games. Then play.

Set up the Collection, add your own PS3 and PS4 files, then import Uncharted 2 or Uncharted 3 multiplayer on your PC. No game files are included.

MP

Before you begin

Windows 10/11 64-bit, a Vulkan 1.3 GPU with current drivers, 16 GB RAM recommended, and a 4-core CPU or better.

For multiplayer you need your own PS4 Collection and your own PS3 Uncharted 3. We support BCES01670, BCUS99086, BCES01692 and BCAS25014. The same import and RPCN setup applies to both Uncharted 2 and Uncharted 3.

The guide does not provide game files, keys, server addresses or account credentials.

01

DOWNLOAD + FIRST START

Install the launcher

Download UCMR_windows.zip and extract it into a normal folder you own, for example D:\Games\Uncharted, not Program Files. Double-click Uncharted Launcher.exe. If SmartScreen warns you, choose More info → Run anyway.

You will see Drake's Fortune, Among Thieves and Drake's Deception at the top. Newer versions show an UPDATE button next to PLAY; saves and settings are kept.

02

PS4 COLLECTION

Add your game and update 1.02

Click a game, press PLAY, and pick your own Collection folder: the one with eboot.bin and sce_sys, often called uroot. To switch folders later, use SETUP → step 1 → Change game folder.

PS4 copies known to work: CUSA02320, CUSA02826, CUSA02343 and CUSA02344. They do not have to be v1.0. Update 1.02 is needed for multiplayer; if your copy is v1.0, add the update separately. Add it through SETUP → step 2 → Choose update folder, or place an extracted update beside the game folder with -patch added to its name.

Good to knowQUICK SETUP sets a preset; DISPLAY, PERFORMANCE and CONTROLS fine-tune it. First launch compiles shaders and may stutter. Insert or R3 + L2 opens the in-game menu. SETUP → step 1 → Check game files verifies your dump.
03

PS3 SOURCES

Collect the Uncharted 3 files

Add the PS3 game folder (PS3_GAME/USRDIR or an extracted ISO) and RPCS3's dev_hdd0/game folder. The RPCS3 folder must contain update 1.19, the game data install (XXXXXXXXXDATA2) and the DLC map packs. Install them in RPCS3 and start the game once.

For character collisions the import also needs a decrypted EBOOT. In RPCS3 choose Utilities → Decrypt PS3 Binaries, select dev_hdd0/game/XXXXXXXXX/USRDIR/EBOOT.BIN, and RPCS3 writes EBOOT.elf beside it. The import finds it by itself.

Fastest pathUncharted 3 BCES01670 and Uncharted 2 NPUA80698 are the known working PS3 versions that get multiplayer running fastest.
04

IMPORT

Convert the multiplayer files

Select Drake's Deception → MULTIPLAYER. Under PS3 Uncharted 3 folders → Add folder, add the game folder and RPCS3's dev_hdd0/game. Optionally choose the decrypted EBOOT if it was not found, or change the multiplayer data folder to another drive. Then press IMPORT.

Conversion takes about 12–15 minutes, depending on hardware. You can close the launcher; the import keeps going. Progress shows on the tab, and Open import log shows the details.

Allow about 20 GB for the multiplayer files. Another 11 GB helps future updates, which are built next to your current files so you can keep playing.

05

PLAY + RPCN ONLINE

Sign in to RPCN, then launch

RPCN sign-in is required before you launch either game. Open the MULTIPLAYER tab for Uncharted 2 or Uncharted 3 and sign in there. If you already set up an RPCN account in RPCS3, use Import from RPCS3; otherwise create one in RPCS3 under Configuration → RPCN first.

The import, DNS and RPCN steps are the same for both games. Use the Uncharted 2 Discord or Uncharted 3 Discord for that game's community DNS.

READY CHECKRPCN signed in under MULTIPLAYER before PLAY

Turn on Start Uncharted 3 with multiplayer and select Drake's Deception → PLAY. On the title screen, Right is Multiplayer and Right Right is Co-op; for LAN Party, press Cross on your profile.

KEEP IT UPDATEDUPDATE refreshes multiplayer files in the background; no re-import needed

If something goes wrong, post import.log from MULTIPLAYER → Open import log together with your GPU and Windows version.

READY TO PLAY

Launch into multiplayer

Once all five checks are complete, start Uncharted 3 with multiplayer and select Play. During play, use Insert or R3 + L2 to open the in-game menu.
